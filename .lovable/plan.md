# Прототип: экран «Матчи» — Court Count

Собираем один статичный мобильный экран по присланному макету. Данные — моковые, без бэкенда. Карточек достаточно, чтобы был скролл.

## Что строим

Единственный экран на `/` — список активных матчей турнира.

### Структура экрана (сверху вниз)

1. **Хедер**: логотип «CC» (плейсхолдер — зелёный + голубой квадраты с буквами, заменю на ваш файл когда пришлёте) + иконка-бургер справа. Тонкая разделительная линия.
2. **Заголовок турнира**: стрелка «назад» + «Первенство г. Люберцы на призы компании "Кухонный Двор"».
3. **Табы**: Матчи (активный) · Настройки · Судьи. Визуальные.
4. **Сегмент статуса**: Активные (выбрана) / Завершённые. Визуальные.
5. **Список карточек** (см. данные ниже). Карточка:
   - Шапка (голубой фон): зелёная точка · корт · стадия · таймер · шеврон.
   - Тело: строки игроков. У подающего — иконка мяча рядом с именем. Справа: текущий гейм в рамке, затем колонки сетов (1–4 в зависимости от матча).
   - Опциональный подвал с иконкой рупора и сообщением.
6. **Sticky-кнопка снизу**: «Создать матч», голубая, во всю ширину. Визуальная.

## Дизайн-токены (`src/styles.css`, oklch)

- `--court-blue` — фон шапок карточек.
- `--court-blue-strong` — подчёркивание активного таба и CTA.
- `--court-green` — индикатор «идёт» и левый квадрат логотипа.
- Скругление карточек ~12px, мягкая тень.

Только семантические токены в компонентах, никаких прямых tailwind-цветов.
