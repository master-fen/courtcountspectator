Цель — ужать вертикальные и горизонтальные зазоры на мобильном, не меняя структуру (заголовок / табы / пилюли остаются отдельными блоками).

### Что меняем

1. **`src/routes/index.tsx`**
   - Верхний `padding` контейнера под шапкой: `12px 0 0` → `8px 0 0`.
   - `gap` между `TournamentTitle` / `SectionTabs` / `StatusPills`: `16px` → `8px`.
   - Горизонтальный `padding` у списка матчей: `0 8px` → `0 12px` (унификация с заголовком, табами и пилюлями).

2. **`src/components/court-count/SectionTabs.tsx`**
   - Высота контейнера табов: `31px` → `28px`.
   - Высота кнопки таба: `31px` → `28px`.
   - Внутренний `padding` кнопки: `2px 8px` → `4px 10px`.
   - Остальное (цвета, шрифт, `borderBottom`) оставляем без изменений.

3. **Остальные компоненты** (`TournamentTitle`, `StatusPills`, `Header`, `MatchCard`) — не трогаем, кроме каскадного эффекта от унификации отступов в пункте 1.

### Ожидаемый результат

- Дополнительно ~20–24px вертикального пространства над первой карточкой матча.
- Единый горизонтальный отступ `12px` для всех элементов в верхней части экрана.
- Более плотные, но всё ещё читаемые табы.
