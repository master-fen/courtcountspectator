# Фиксация кнопки внизу и скрытие скроллбара

## Изменения

1. **`src/routes/index.tsx`**
   - Кнопку «Создать матч» вынести из колонки контента и сделать `position: fixed; bottom: 0; left: 50%; transform: translateX(-50%);` шириной 360px, поверх карточек.
   - Список карточек получает нижний `padding-bottom` ≈ 76px (40 кнопка + 12+12 паддинги плашки + запас), чтобы последняя карточка не пряталась под кнопкой.
   - Внешняя колонка экрана: `gap: 4` оставляем только между Header и блоком контента; нижняя плашка с кнопкой больше не часть колонки.

2. **`src/components/court-count/CreateMatchButton.tsx`**
   - Внутренние стили остаются (плашка `width: 360, padding: 12 0`, кнопка `306×40` `#4DB2EA`). Позиционирование добавляется на уровне обёртки в `index.tsx`, чтобы компонент оставался переиспользуемым; либо добавить `style={{ position: "fixed", bottom: 0 }}` прямо в компоненте — выберу второй вариант, проще.

3. **`src/styles.css`** — скрыть скроллбар глобально, оставив прокрутку:
   ```css
   html { scrollbar-width: none; }
   html::-webkit-scrollbar { display: none; }
   ```
   Добавляю в конце файла.

## Что не трогаем

- Размеры, цвета, шрифты, отступы внутри карточек.
- Поведение скролла — он остаётся, прячется только полоска.
