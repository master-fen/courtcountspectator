## Проблема

При промежуточных значениях `progress` (например, 0.4–0.6) оба слоя заголовка — полный многострочный и компактный однострочный — одновременно частично прозрачны и наложены друг на друга. Из-за этого виден «двойной» текст / эффект призрака, как на скриншоте. Сейчас кроссфейд распределён по всему диапазону скролла, поэтому такое состояние очень легко поймать.

## Решение: «защёлкивающийся» кроссфейд + сдвиг по времени

Вместо плавного кроссфейда через весь диапазон делаем переход быстрым и сдвинутым так, чтобы полный и компактный слои **почти не пересекались по непрозрачности**.

### Изменения только в `src/components/court-count/TournamentTitle.tsx`

1. **Высота контейнера** — оставляем плавной (геометрия меняется как и сейчас, чтобы layout не «прыгал»).
2. **Полный слой (многострочный)**:
   - Виден полностью при `p < 0.35`.
   - Резко исчезает в диапазоне `p ∈ [0.35, 0.5]` (короткий fade-out ~0.15 ширины прогресса).
   - При `p ≥ 0.5` — `opacity: 0`, `pointer-events: none`.
3. **Компактный слой (однострочный)**:
   - Скрыт при `p ≤ 0.5`.
   - Резко появляется в диапазоне `p ∈ [0.5, 0.65]`.
   - При `p ≥ 0.65` — `opacity: 1`.
4. **Никаких translateY** на слоях — только opacity. translateY усиливал ощущение «дёрганья», когда оба слоя видны.
5. Формулы:
   ```
   fullOpacity    = clamp01((0.5 - p) / 0.15)
   compactOpacity = clamp01((p - 0.5) / 0.15)
   ```
   В середине окна перехода (`p ≈ 0.5`) оба слоя имеют opacity ≈ 0 буквально на 1–2 кадра скролла — «защёлка» вместо размазанного кроссфейда.
6. Для `lines === 1` поведение прежнее (статичный заголовок, без анимации).

### Что это даёт

- Пограничного состояния с двумя видимыми текстами практически нет — переход проходится за очень короткий участок скролла.
- Геометрия (высота, layout табов и поиска под заголовком) по-прежнему меняется плавно, без рывков.
- Никаких изменений в `tournament.$id.tsx` и логике подсчёта строк не требуется.

## Критерии готовности

- Медленно скроллю турнир с длинным названием — нет момента, когда одновременно видны полный и компактный заголовок наложенными друг на друга.
- Высота шапки по-прежнему меняется плавно, контент под ней не прыгает.
- Турниры с однострочным названием не анимируются (как и раньше).
