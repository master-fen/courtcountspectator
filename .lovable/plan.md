## Что строим

Страница «Турниры» — список карточек турниров с табами «Текущие / Завершенные» и поиском. Тапаем карточку → открывается уже существующая страница турнира (счёт матчей / Информация / Настройки / Судьи).

Хедер (логотип + бургер) остаётся **точно таким же**, как в нашем прототипе — версия из присланного скриншота игнорируется.

## Маршруты

- `/` → **новый список турниров** (`src/routes/index.tsx` переписывается).
- `/tournament/$id` → **текущая страница** с матчами и информацией (контент `index.tsx` переносится сюда в `src/routes/tournament.$id.tsx`).
- В `BurgerMenu` пункт «Турниры» становится `<Link to="/">` и закрывает меню.
- Стрелка «Назад» в `TournamentTitle` на детальной странице ведёт на `/`.

## Моки

Новый файл `src/lib/mock-tournaments.ts`:

```ts
type Tournament = {
  id: string;
  title: string;
  city: string;        // "Тосно", "Пермь", ...
  dateLabel: string;   // "25 августа — 10 сентября"
  info?: string;       // плашка с важной инфой (опционально)
  status: "current" | "completed";
};
```

Список (всё `status: "current"`, кроме отдельного состояния «Завершенные»):

1. `lyubertsy` — **Первенство г. Люберцы на призы компании «Кухонный Двор»**, Люберцы, текущие даты — это **наш существующий турнир**, у него настоящие матчи (`mockMatches`).
2. `tosno` — Кубок Тосно теннис академии, Тосно, 25 августа — 10 сентября, плашка «Какая-то очень важная информация…».
3. `perm` — Кубок Тосно теннис академии с очень длинным названием, чтобы было видно перенос по словам, Пермь, 15 августа — 3 сентября, плашка с инфо.
4. `vyborg` — Турнир посвященный памяти ценам на оперативную память, Выборг, 25 августа — 10 сентября.
5. `spb` — Кубок прекрасного дорогого грузинского сухого вина 1934 года, Санкт-Петербург, 25 августа — 10 сентября.

У всех турниров матчи одинаковые — используют тот же `mockMatches`, как просил пользователь. Это значит на детальной странице любой турнир показывает один и тот же набор матчей, меняется только заголовок в `TournamentTitle`.

Таб «Завершенные» — пока пустой со скромным placeholder («Завершённых турниров пока нет»). Поиск — простой фильтр по `title` (контролируемый input, без сабмита).

## Компоненты

Новые в `src/components/court-count/`:

- `TournamentsListHeader.tsx` — заголовок «Турниры» (Headline 1).
- `TournamentsTabs.tsx` — табы «Текущие / Завершенные», стиль идентичен `SectionTabs` (нижняя подсветка, primary колор).
- `TournamentsSearch.tsx` — pill-инпут с иконкой лупы, фон `--court-surface-soft` (или `#E1E8ED` через токен), placeholder «Поиск по названию».
- `TournamentCard.tsx` — карточка из скриншота:
  - Title (Body Medium Bold, до 3 строк, перенос по словам).
  - Ряд: иконка-кубок 58×54 в скруглённом сером прямоугольнике (`Trophy` из lucide, заливка золотая `#E9C943`), затем колонка с двумя строками: `🇷🇺 city` (флаг из эмодзи), `📅 dateLabel`. Иконки `Flag`/`CalendarBlank` из lucide.
  - Если есть `info` — серая плашка снизу с текстом 12px.
  - Border `0.5px solid var(--court-text-soft)`, radius 4, padding 12, gap 8.
  - Клик по карточке → `navigate({ to: "/tournament/$id", params: { id } })`.

## Детальная страница `/tournament/$id`

Перенос текущего `Index` из `src/routes/index.tsx` в `src/routes/tournament.$id.tsx`. Внутри читаем `id` через `Route.useParams()`, ищем турнир в моках, берём его `title` для `TournamentTitle`. Если турнир не найден — `notFoundComponent`. Если турнир не `lyubertsy` — матчи всё равно те же `mockMatches` (по запросу).

В `TournamentTitle` стрелка «Назад» становится кликабельной: `useNavigate()({ to: "/" })`.

## Что НЕ меняем

- Header / Logo / BurgerMenu (только пункт «Турниры» делаем ссылкой).
- Дизайн `SectionTabs`, `StatusPills`, `MatchCard`, `InfoTab`, `MatchDetailsSheet`, `CreateMatchButton` — без изменений.
- Существующие моки `mockMatches`, `mockDocuments` — не трогаем.
- Темизация (тёмная тема): новые компоненты используют существующие токены `--court-surface`, `--court-text-strong`, `--court-text-soft`, `--court-primary`. Никаких хардкод-цветов.

## Критерии готовности

- На `/` отображается список из 5 турниров, табы и поиск работают.
- Тап по любой карточке открывает существующую страницу матчей с правильным заголовком турнира.
- Кнопка «Назад» на детальной странице и пункт «Турниры» в бургере возвращают на `/`.
- Хедер визуально идентичен текущему (не из скриншота).
- Tемная тема корректно применяется к новым экранам.
