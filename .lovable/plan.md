## Что делаем

Добавляем экран «Мои турниры» как корневой (`/`). Текущий экран матчей переезжает на `/tournaments/$tournamentId`. Существующая стрелка ← в `TournamentTitle.tsx` начинает работать — ведёт на `/`.

## Роуты

- `/` → новый экран **Мои турниры**.
- `/tournaments/$tournamentId` → текущий экран матчей. Если id не найден → `notFoundComponent`.

## Моки турниров

```ts
type Tournament = {
```

3 турнира (все «текущие», завершённые не добавляем):
1. «Кубок Тосно теннис академии с очень длинным названием, чтобы было видно перенос по словам» — Тосно, 25 августа — 10 сентября.
2. «Первенство г. Люберцы на призы компании „Кухонный Двор"» — Люберцы, 12 — 20 сентября (нынешний турнир).
3. «Открытый турнир Москвы среди любителей» — Москва, 1 — 8 октября.

Существующие 6 матчей из `mockMatches` распределяю между ними (например 3 / 2 / 1).

Вкладка «Завершённые» рендерит пустой список (плейсхолдер «Пока ничего нет» либо просто пусто — уточни, если надо иначе).

## Стрелка «назад»

В `TournamentTitle.tsx` стрелка уже есть. Делаю кнопку: оборачиваю `ArrowLeft` в `<Link to="/">` (или `<button onClick={() => navigate({to: "/"})}>`), с `aria-label="Назад"`. Больше ничего в компоненте не трогаю.

- `TournamentCard.tsx` — карточка из макета:
  - рамка `0.5px solid var(--court-border)`, `border-radius: 6`, фон `var(--court-surface)`, ширина 344;
  - заголовок (название) — `var(--font-body)`, 700, 16/22, `--court-text-strong`, перенос по словам;
  - тело: плашка 64×64 с иконкой кубка (`Trophy` из lucide, цвет жёлтый как в макете) + справа две строки: 🇷🇺 + город, `Calendar` + диапазон дат.

- `PageTitle.tsx` — общий заголовок страницы («Мои турниры»). Шрифт display, 24/28, `--court-text-strong`.
