## Цель
Добавить свайп-закрытие бокового меню (BurgerMenu) на мобильных устройствах, без кнопки-крестика.

## Что сделаем
1. **Touch-свайп** — повесим обработчики `touchstart` / `touchmove` / `touchend` на панель меню (`<aside>`).
   - Отслеживаем горизонтальное движение пальца.
   - Если пользователь тянет вправо (dx > 0) на пороге ≥ 80 px — вызываем `onClose()`.
   - Вертикальный скролл списка должен продолжать работать: свайп закрывает только при явном горизонтальном жесте.
2. **Сохранить текущие способы** — закрытие по клику на overlay и по Escape остаётся без изменений.
3. **Без крестика** — явная кнопка X в углу меню не добавляется (по запросу пользователя).

## Технические детали
- Меню уже рендерится через `fixed` overlay + `aside` с `justify-content: flex-end`.
- Никаких новых npm-зависимостей: реализация на чистых DOM touch-событиях.
- Порог свайпа и чувствительность подбираем так, чтобы не конфликтовать с вертикальным скроллом (`Math.abs(dx) > Math.abs(dy)`).

## Критерии готовности
- [ ] Свайп вправо внутри меню закрывает его.
- [ ] Вертикальный скролл элементов меню работает без помех.
- [ ] Overlay-click и Escape по-прежнему закрывают меню.
- [ ] Никаких UI-изменений на десктопе.
